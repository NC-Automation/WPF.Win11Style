Package metadata now lives in Win11Style.csproj (the .nuspec is no longer used).
Dependencies are generated automatically from the PackageReference items.

1. Edit Win11Style.csproj to increment <Version> and update <PackageReleaseNotes>.
2. Pack:
   dotnet pack Win11Style\Win11Style.csproj -c Release -o nupkg
3. Push (Azure DevOps feed):
   dotnet nuget push nupkg\NCAutomation.Win11Style.<version>.nupkg --source https://pkgs.dev.azure.com/NCAutomation/_packaging/NCAutomation/nuget/v3/index.json --api-key az
